# Qiunix: Apollo - Update
> Plugin version update v10140-171126-S. This update focuses on optimizing the daemon engine, especially in the free version, as well as optimizing AxBridge integration within the plugin's WebUI.

## What's New?
- Daemon Engine Optimization
  > In the free version, the daemon engine has now reached version `10190`, while the Pro daemon engine has reached version `10210`. The difference between these two engines is quite significant, particularly in tweak integration. However, we have re-optimized the engine performance for the free version along with several adjustments. For the Pro version, we have added several features and optimized the thermal tweak system by changing how it operates.
- AxBridge Integration Optimization
  > In the first patch update last November, we released AxBridge integration. However, in Qiunix: Apollo v10135, there were many things we hadn't added yet alongside numerous bugs. In this patch, we have resolved those issues, and AxBridge integration now runs smoothly.
- Added Daemon Beta Test User Option
  > Adding this option allows the developer to release beta version daemon patches so they can be tested first by beta users. Later on, I will add a registration form for IDs to grant beta test access. We took this step so the developer can see how the engine performs on users' devices, as unpredictable issues often occur.
- Game Manager Exclusive to AxManager WebUI
  > This means the Game Manager menu can only be used in the AxManager WebUI. If you use AxBridge to open the Qiunix plugin WebUI, you will not be able to access the Game Manager menu.
- And many other updates that we have provided.

> In essence, the update in version 10140 focuses more on optimizing the system engine and AxBridge integration. We hope this update minimizes bugs and other issues.
