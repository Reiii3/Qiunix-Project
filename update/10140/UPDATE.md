# Qiunix: Apollo - Update
> Update version plugin v10140-171126-S, update ini terfokus pada optimalisasi daemon engine terutama di versi free serta pengoptimalan integrasi AxBridge di webui Plugin nya

## Apa yang baru?
- Optimalisasi Daemonn Engine
  > di versi free sekarang daemon engine suddah memasuki veri `10190` dan di versi daemon engine pro sudah memasuki versi1 `10210` perbedaan kedua engine ini sangat jauh terutama pada intehrasi tweak nya, namun kami sudah mengoptimalisasikan ulang kinerja engine untuk versi free dan beberapa penyesuaian, untuk versi pro kami sudah menambahkan beberapa fitur serta optimasi system tweak thermal yang kami ubah cara kerja nya
- Optimasi Integrasi AxBridge
  > di update patch pertama bulan november kemarin kami merilis integrasi AxBridge namun di versi Qiunix: Apollo v10135 itu terdapat banyak hal yang belum kami tambahkan serta banyak sekali bug yang terjadi, dan di patch kali ini kami sudah menyelesaikann masalah itu dan integrasi AxBridge sudah berjalan dengan lancar
- Penambahan User Beta Test Daemon
  > Penambahan opsi ini memungkin kan developer dapat merilis patch beta version daemon agar daemon dapat di test terlebih dahulu kepada user beta, yang nanti nya saya akan menambahkan form untuk pendaftaran id agar dapat menggunakan akses beta test, upaya ini kami ambil agar developer tau bagaimana engine ini dapat berkerja di device user, di karenakan sering kali terjadi hal-hal yang tidak dapat kami prediksi
- Game Maanager Only AxManager WebUI
  > Yang berarti menu game manager hanya dapat di gunakan di webui axmanager saja jika kalian menggunakan AxBridge untuk membuka webui plugin qiunix maka kalian tidak dapat mengakses menu game manager
- Dan Masih banyak lagi update yang kami berikan

> Inti nya update di versi 10140 ini lebih terfokus pada pengoptimalan system engine dan juga pengoptimalan integrasi AxBridge, kami harap di update ini sangat minim terjadi nya sebuah bug dan juga beberapa masalah lain nya
