# Qiunix: Apollo - Update
> Qiunix: Apollo v10130-221026-S update. In this update, I focused heavily on the WebUI. In previous versions, the WebUI was very heavy and sluggish, so I needed to optimize it to make it comfortable and responsive to use.

## What's Changed?
- WebUI Improvements
  > I spent almost 3 weeks doing a complete overhaul of the WebUI, and I have optimized it to the absolute maximum of my abilities.
- Dynamic Feature Additions
  > This is one of the changes that will greatly help with maintenance and the addition of new features. With this dynamic UI, I no longer need to constantly update the codebase.
- Daemon Performance Optimization
  > I did a reconfiguration and this time I also ran tests using a CPU throttling tool. The result is that in v10200, the Qiunix: Apollo daemon has become highly optimal. I also removed some old tweaks and added new ones.
- Integration With a New Binary (`QiunixT`)
  > QiunixT is a binary available exclusively in the Pro Daemon version. This binary contains many new tweaks that I have added. With this binary, it is much easier for me to configure tweaks separately from the main daemon.
- And many other updates.

> With this update, I hope the daemon's performance can help boost your phone's performance. This is an official update from the developer, so please read this documentation.
